# GlaucoMap

**AI-Assisted Glaucoma Progression Mapping & Treatment Scenario Simulation**

> *Clinical Decision-Support & Research Prototype for Healthcare AI Hackathon (48-Hour Build)*

---

## Project Overview

GlaucoMap is an investigational clinical decision-support platform designed to assist ophthalmologists and eyecare specialists in analyzing digital Optical Coherence Tomography (OCT) and Retinal Nerve Fiber Layer (RNFL) data.

The system is being engineered to provide:
- Glaucoma progression risk estimation with calibrated uncertainty bounds
- OCT/RNFL structural analysis across standardized anatomical sectors
- Grad-CAM visual explainability maps
- Atypical-pattern and image acquisition quality fault detection
- Longitudinal progression rate tracking
- 24-month progression forecasting
- Hypothetical Intraocular Pressure (IOP) reduction what-if scenario simulations
- Clinician-facing progression summaries

---

## Important Medical Safety Notice

GlaucoMap is a **research and clinical decision-support prototype**.
- It is **not** an autonomous diagnostic device or a replacement for an ophthalmologist's clinical judgment.
- Outputs generated by AI models are strictly **model-generated estimates**, not definitive diagnoses.
- Treatment scenario outputs are strictly **hypothetical mathematical simulations**, not deterministic medical outcomes.
- The platform incorporates input validation and quality detection to flag uninterpretable data rather than generating unreliable predictions.

## Local Setup Instructions

### 1. Prerequisites
- Python 3.10+ (tested on Python 3.12)
- Node.js 18+ (tested on Node v24) & npm
- Docker Desktop (for containerized PostgreSQL)

### 2. Clone and Configure Environment
Copy the example environment file:
```bash
cp .env.example .env
```

### 3. Backend Setup
Create and activate a virtual environment, then install dependencies:

```bash
# Windows (PowerShell)
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r backend/requirements.txt

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
pip install -r backend/requirements.txt
```

### 4. Frontend Setup
Install frontend dependencies:

```bash
cd frontend
npm install
cd ..
```

## Running the Application (10 PM Checkpoint Demo)

### 1. Prerequisites
- Python 3.10+ (tested on Python 3.12)
- Node.js 18+ (tested on Node v20/24) & npm

### 2. Backend Setup & Startup (FastAPI)
From the project root:
```bash
# Windows (PowerShell)
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r backend/requirements.txt
pip install -r ml/requirements.txt

# Start backend server
.\venv\Scripts\python -m uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 8000
```
- Interactive Swagger API Documentation: `http://127.0.0.1:8000/docs`
- Health check endpoint: `http://127.0.0.1:8000/health`

### 3. Frontend Setup & Startup (React + Vite)
In a second terminal, from the project root:
```bash
cd frontend
npm install
npm run dev
```
Open your browser at `http://localhost:5173`.
